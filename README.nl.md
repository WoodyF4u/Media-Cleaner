# Media Cleaner

Een Joomla 6-beheercomponent die de hele website doorzoekt op mediabestanden (afbeeldingen, video, audio, pdf) en een sorteerbaar, filterbaar overzicht toont met thumbnails, bestandsgroottes, locaties, en of elk bestand nog ergens op de site wordt gebruikt.

## Functies

- Doorzoekt de hele website recursief; overzicht wordt gecachet en is te sorteren/filteren
- Koppelingscontrole over artikelen, modules, categorieën, menu-items, custom fields, contactpersonen en advertenties, met dieptelinks naar de exacte beheerpagina
- Onder elk gekoppeld bestand een directe link naar precies waar het wordt gebruikt
- Negeerlijst voor bestanden die je bewust wilt behouden, ook al lijken ze ongebruikt
- Veilig verwijderen: niet-gekoppelde bestanden gaan eerst naar een beveiligde tijdelijke map, later terug te zetten of definitief te verwijderen
- Bulkacties (verwijderen / negeren / herstellen) via één keuzelijst
- WebP-compressie met één klik voor gekoppelde afbeeldingen, opgeslagen naast het origineel
- Ondersteuning voor donkere modus
- Ingebouwde Help-pagina

## Vereisten

- Joomla 6.x
- MySQL

## Installatie

1. Download de laatste `.zip` via de [Releases](../../releases)-pagina.
2. Ga in de Joomla-beheeromgeving naar **Systeem → Installeren → Extensies** en upload de zip.
3. Open **Componenten → Media Cleaner** en klik op **Scan opnieuw uitvoeren**.

## Updates

Deze component heeft een eigen updateserver, dus nieuwe versies verschijnen automatisch onder **Systeem → Beheer extensies → Updates** zodra ze hier op GitHub worden gepubliceerd.
